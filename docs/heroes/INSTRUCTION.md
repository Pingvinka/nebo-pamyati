# 📘 ПОДРОБНАЯ ИНСТРУКЦИЯ ПО РАБОТЕ С САЙТОМ "ВЕЧНАЯ СЛАВА ГЕРОЯМ"
## 🎯 ВВЕДЕНИЕ
Добро пожаловать! Этот сайт создан для увековечивания памяти героев Великой Отечественной войны. В этой инструкции вы найдете пошаговое руководство по добавлению информации о героях и публикации сайта.
---
## 📁 СТРУКТУРА ПРОЕКТА
После сборки проекта (команда `npm run build`) у вас будет папка `dist` со следующей структурой:
```
dist/
├── index.html                    # Главная страница сайта
├── assets/                       # CSS, JS и другие файлы (автоматические)
├── heroes/                       # Страницы героев
│   ├── hero-template.html        # Шаблон для создания новых страниц
│   ├── ivanov-ivan.html          # Пример готовой страницы
│   └── [другие страницы героев]
└── media/                        # Ваши медиафайлы
    ├── photos/                   # Фотографии героев
    │   ├── ivanov-ivan.jpg
    │   └── ...
    └── videos/                   # Видео (опционально)
        ├── ivanov-ivan.mp4
        └── ...
```

## 🚀 ШАГ 1: ПОДГОТОВКА МАТЕРИАЛОВ
### 1.1 Сбор информации от одноклассников
Попросите каждого ученика предоставить:
1. **Текстовый файл (.txt)** с информацией:
   - ФИО героя
   - Годы жизни
   - Звание
   - Награды
   - Участие в боях
   - История (рассказ о герое, минимум 500 слов)
2. **Фотографию** (форматы: .jpg или .png):
   - Желательно портретное фото
   - Хорошее качество (минимум 800x1000 пикселей)
3. **Видео** (опционально, формат .mp4):
   - Рассказ о герое или видеоархивы
   - Длительность: 2-5 минут
### 1.2 Организация файлов
Создайте на компьютере папку `ПРОЕКТ_ГЕРОИ` со структурой:
```
ПРОЕКТ_ГЕРОИ/
├── тексты/
│   ├── ivanov_ivan.txt
│   ├── petrov_petr.txt
│   └── ...
├── фото/
│   ├── ivanov_ivan.jpg
│   ├── petrov_petr.jpg
│   └── ...
└── видео/
    ├── ivanov_ivan.mp4
    ├── petrov_petr.mp4
    └── ...
```
**ВАЖНО:** Называйте файлы латиницей, без пробелов (используйте дефис или подчеркивание).

## 🛠 ШАГ 2: СОЗДАНИЕ СТРАНИЦЫ ГЕРОЯ
### 2.1 Копирование шаблона
1. Откройте папку `dist/heroes/`
2. Скопируйте файл `hero-template.html`
3. Переименуйте его, например: `ivanov-ivan.html`
   - Используйте латиницу
   - Без пробелов (через дефис)
   - Расширение `.html`
### 2.2 Редактирование страницы
Откройте файл `ivanov-ivan.html` в любом текстовом редакторе (Notepad++, VS Code, или даже Блокнот).
#### А) Замена заголовка (строка 6):
```html
<!-- БЫЛО: -->
<title>Небо героя: [ИМЯ ГЕРОЯ]</title>
<!-- СТАЛО: -->
<title>Небо героя: Иванов Иван Иванович</title>
```
#### Б) Замена фотографии (строка ~347):
**Сначала:** Скопируйте фото в папку `dist/media/photos/`
```html
<!-- БЫЛО: -->
<div class="photo-placeholder">📷</div>
<!-- СТАЛО: -->
<img src="../media/photos/ivanov-ivan.jpg" alt="Иванов Иван Иванович" class="hero-photo">
```
**ВАЖНО:** Путь к фото - `../media/photos/имя_файла.jpg`
#### В) Заполнение информации (строки ~355-380):
```html
<div class="info-item">
    <span class="info-label">Полное имя:</span>
    <span>Иванов Иван Иванович</span>  <!-- Замените -->
</div>
<div class="info-item">
    <span class="info-label">Годы жизни:</span>
    <span>1920 - 1945</span>  <!-- Замените -->
</div>
<div class="info-item">
    <span class="info-label">Звание:</span>
    <span>Рядовой</span>  <!-- Замените -->
</div>
<div class="info-item">
    <span class="info-label">Награды:</span>
    <span>Орден Красной Звезды, Медаль "За отвагу"</span>  <!-- Замените -->
</div>
<div class="info-item">
    <span class="info-label">Участие в боях:</span>
    <span>Сталинградская битва, Курская дуга</span>  <!-- Замените -->
</div>
```
#### Г) Вставка истории (строка ~390):
Откройте файл `ivanov_ivan.txt`, скопируйте весь текст и вставьте вместо текста-заглушки:
```html
<div class="story-text">
    Иван Иванович Иванов родился в 1920 году...
    
    [Вставьте сюда весь текст из .txt файла]
    
    Мы помним. Мы гордимся.
</div>
```
**СОВЕТ:** Разделяйте абзацы пустыми строками для лучшей читаемости.
#### Д) Добавление видео (опционально, строка ~405):
**Сначала:** Скопируйте видео в папку `dist/media/videos/`
```html
<!-- БЫЛО: -->
<div class="video-placeholder">
    <div class="video-placeholder-icon">🎬</div>
    <p>Видео будет добавлено позже</p>
</div>
<!-- СТАЛО: -->
<video controls>
    <source src="../media/videos/ivanov-ivan.mp4" type="video/mp4">
    Ваш браузер не поддерживает видео.
</video>
```
#### Е) Сохранение
Нажмите `Ctrl + S` или `Файл → Сохранить`.

## 📝 ШАГ 3: ДОБАВЛЕНИЕ ГЕРОЯ НА ГЛАВНУЮ СТРАНИЦУ
### 3.1 Открытие главной страницы
Откройте файл `dist/index.html` в текстовом редакторе.
### 3.2 Поиск секции героев
Найдите в коде (Ctrl + F) текст: `heroes-grid`
Вы увидите код карточек:
```html
<div class="heroes-grid">
    <!-- Карточки героев -->
    <div class="hero-card">...</div>
    <div class="hero-card">...</div>
    ...
</div>
```
### 3.3 Копирование и редактирование карточки
Скопируйте ОДНУ карточку (от `<div class="hero-card">` до закрывающего `</div>`):
```html
<div class="hero-card" style="animation-delay: 0.5s">
    <div class="hero-card-inner">
        <div class="hero-photo-icon">📷</div>
        <h3 class="hero-name">Иванов Иван Иванович</h3>  <!-- Замените -->
        <a href="/heroes/ivanov-ivan.html" class="hero-link">  <!-- Замените путь -->
            Узнать историю →
        </a>
    </div>
</div>
```
**ЧТО МЕНЯТЬ:**
1. `animation-delay` - увеличьте на 0.1s для каждой новой карточки (0s, 0.1s, 0.2s, 0.3s...)
2. `<h3>` - ФИО героя
3. `href` - путь к странице героя (`/heroes/имя-файла.html`)
### 3.4 Вставка карточки
Вставьте скопированный код ПЕРЕД карточкой "Добавить героя" (та, что с `hero-card-add`).
### 3.5 Сохранение
Нажмите `Ctrl + S`.

## 🌐 ШАГ 4: ПУБЛИКАЦИЯ НА NETLIFY (БЕСПЛАТНО)
### 4.1 Регистрация на Netlify
1. Перейдите на сайт: https://www.netlify.com/
2. Нажмите **"Sign up"** (Зарегистрироваться)
3. Выберите регистрацию через **GitHub** или **Email**
4. Подтвердите email (если регистрировались по почте)
### 4.2 Подготовка папки для загрузки
1. Откройте папку вашего проекта
2. Найдите папку `dist` (она появилась после `npm run build`)
3. Скопируйте папку `media` (с фото и видео) ВНУТРЬ папки `dist`
4. Убедитесь, что в `dist` есть:
   - `index.html`
   - папка `heroes/`
   - папка `media/`
   - папка `assets/`
### 4.3 Загрузка сайта (Drag & Drop)
1. Войдите в свой аккаунт Netlify
2. На главной странице найдите область с текстом:
   **"Want to deploy a new site without connecting to Git? Drag and drop your site folder here"**
   
3. **ПЕРЕТАЩИТЕ** папку `dist` прямо в эту область
   - Просто зажмите папку мышкой и перетащите в окно браузера
4. Netlify начнет загрузку. Подождите 30-60 секунд.
5. После завершения вы увидите:
   - Зеленую галочку
   - Ссылку на ваш сайт (например: `https://random-name-123456.netlify.app`)
### 4.4 Изменение имени сайта (опционально)
1. Нажмите на название сайта (random-name-123456)
2. Перейдите в **"Site settings"**
3. Нажмите **"Change site name"**
4. Введите своё имя (например: `geroi-vov-11a`)
5. Ваш сайт теперь доступен по адресу: `https://geroi-vov-11a.netlify.app`
### 4.5 Обновление сайта
Если вы добавили нового героя или исправили ошибки:
1. Выполните команду `npm run build` заново
2. Скопируйте папку `media` в новую папку `dist`
3. Перейдите на Netlify → ваш сайт → **"Deploys"**
4. Перетащите новую папку `dist` в область **"Drag and drop"**
5. Готово! Сайт обновлен.

## 💡 СОВЕТЫ И РЕКОМЕНДАЦИИ
### ✅ DO (Делайте так):
1. **Проверяйте пути к файлам** - одна ошибка в пути, и фото не загрузится
2. **Используйте латиницу** в названиях файлов (ivanov-ivan.jpg, а не иванов-иван.jpg)
3. **Сжимайте большие фото** - используйте онлайн-сервисы (например, tinypng.com)
4. **Делайте резервные копии** - перед каждым большим изменением копируйте папку `dist`
5. **Тестируйте локально** - откройте `dist/index.html` в браузере ПЕРЕД загрузкой на Netlify
### ❌ DON'T (Не делайте так):
1. **Не редактируйте файлы в папке `src`** после сборки (они не влияют на `dist`)
2. **Не используйте пробелы** в названиях файлов (используйте дефис или подчеркивание)
3. **Не загружайте видео больше 50 МБ** - Netlify бесплатный аккаунт имеет лимиты
4. **Не удаляйте файлы из `assets`** - они нужны для работы сайта
5. **Не забывайте про `media`** - всегда копируйте её в `dist` перед загрузкой

## 🐛 РЕШЕНИЕ ПРОБЛЕМ
### Проблема 1: Фото не отображается
**Решение:**
- Проверьте путь: `../media/photos/имя-файла.jpg`
- Убедитесь, что файл скопирован в `dist/media/photos/`
- Проверьте расширение (.jpg, .jpeg или .png)
- Название файла должно совпадать ТОЧНО (учитывается регистр)
### Проблема 2: Видео не воспроизводится
**Решение:**
- Убедитесь, что формат `.mp4` (другие форматы могут не работать)
- Проверьте размер файла (не больше 50 МБ)
- Используйте кодек H.264 для совместимости
### Проблема 3: Ссылка на героя не работает
**Решение:**
- Проверьте путь в `href`: `/heroes/имя-файла.html`
- Убедитесь, что файл существует в `dist/heroes/`
- Название должно совпадать (с учетом регистра)
### Проблема 4: Сайт не загружается на Netlify
**Решение:**
- Проверьте размер папки `dist` (не больше 100 МБ для бесплатного аккаунта)
- Убедитесь, что в папке есть `index.html` в корне
- Попробуйте перезагрузить страницу и перетащить снова
### Проблема 5: Стили не применяются
**Решение:**
- НЕ трогайте папку `assets` - она генерируется автоматически
- Если что-то сломалось, пересоберите проект: `npm run build`

## 🎓 ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ
### Как добавить больше облаков на фон?
В файле `src/index.css` найдите секцию с классами `.cloud-1`, `.cloud-2` и т.д. Скопируйте один из них, измените номер и параметры `width`, `height`, `top`, `left`.
### Как изменить цвета?
Основные цвета:
- Небо: `#E0F2FE`, `#BAE6FD`, `#F0F9FF`
- Оранжевый (акцент): `#d97706`, `#f59e0b`
- Белый: `#ffffff`
Найдите эти коды в файлах и замените на свои.
### Как добавить музыку на фон?
Это требует дополнительного кода. Если нужно - обратитесь к преподавателю или программисту.
